# JobInsight 数据契约与统计口径

## 目标与授权

将招聘数据整理为后续开发可执行的字段与统计约定，允许缩减无法支撑的分析方向。用户已同意创建独立 Trellis 任务，选择本轮仅交付文档，并在审阅字段重设计方案后要求 Implement the plan。本任务只落实该数据方案，不扩大为完整产品或工程初始化。

## 已确认背景

- 工作区尚无 Git 仓库、业务代码或应用依赖。FastAPI、Vue 3 + TypeScript、MongoDB 为此前选定方向，本任务不锁定配套工具或版本。
- 核心输入是工作区外现有 UTF-8 BOM CSV：21列岗位主表、技能字典、岗位技能关系，原始文件只读。
- 实测、SHA-256、覆盖、关联及异常证据集中记录于 research/data-audit.json；快照数量不是运行时常量。
- 00-bootstrap-guidelines 负责通用开发规范，与本任务相关但不在本次完成范围，不将其标为完成。

## 需求

- R1：保留21个来源字段，定义类型、来源、空值、展示/筛选/分析用途；experience_min_years、recruitment_headcount 降为保留字段，不作为主要统计。新增 job_category 和嵌套 skills，不冒充已建库。
- R2：规则分类与离线人工/AI独立分类并行；固定11类，允许未分类。约定按来源 id 回填的格式、依据、来源、状态、冲突处理及最终类别；不接模型 API，不建设复核页面。
- R3：来源主表除 id/source_url 外19列完全一致的行分组，保留全部来源ID，按ID字典序最小记录展示，技能并集；先分组再筛选、统计和分页，保持一致。明确重复组内最终类别的决定规则。
- R4：规范省级名称但不猜测城市；薪资有效闭区间计算中点，以中点中位数比较并显示样本量；有效岗位组不足5个不参与薪资排名。已知原文倒置不参与统计，其他来源差异保留交接值并披露；缺上限不补齐。
- R5：技能标注比例分母为全部筛选后岗位组，同时展示覆盖率；无标签不当作无需求，不因技能展开重复算薪资。学历按要求标签分组而非个人学历因果推断。
- R6：首版分析为省级/岗位类别薪资、学历分布及薪资、技能标签频次与覆盖；不纳入行业/全国城市榜、经验年限影响、个人涨薪预测、完整能力提取或最佳学习路线。
- R7：提供字段字典、分类说明、离线复核格式、统计口径、数据修正清单；同步交接入口和Trellis规范引用。数据修正仅列工作项，不能标为已执行。

## 验收

- A1/R1：文档完整映射21个源字段，准确记录关系文件与新增字段，区分来源记录、业务分组及复核记录。
- A2/R2：11类及未分类有边界、歧义规则和明确/多岗位/笼统校招/冲突示例；复核状态和来源组合可检验，AI结果不自动确认为人工复核。
- A3/R3：实测3000唯一ID、2251组、305重复组、749重复余量、833有技能组；未来重算。技能合并、类别冲突、查询顺序均明确。
- A4/R4/R5：有缺失/倒置/小样本/空分母/技能交叉用例，地区映射覆盖当前错误别名，明确来源差异的处理与限制。
- A5/R6/R7：各文档一致描述本次范围及待开发状态，无安装、数据改写或未经授权的新功能。
- A6：Markdown本地链接、JSON/JSONL、原始文件哈希及覆盖检查通过，独立Trellis复核无未解决阻塞问题。

## 不在本次范围

工程骨架、Git初始化、依赖安装、数据库落地、导入/分类脚本、批量AI分类或真实数据修正、接口与页面、全套前后端规范。文档示例是契约示例，不是生产分类或修正数据。
